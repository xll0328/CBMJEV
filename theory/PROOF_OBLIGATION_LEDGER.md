# 证明义务账本

版本：2026-09-23。对象：[理论结果与适用边界反例](THEORY_APPENDIX.md)。数学闭合状态与真实实现满足假设的状态分开记录；后者绝不因证明成立而自动通过。

## 1. 依赖 DAG

```text
固定类型化概念接口 + 纯函数/独立随机数 + 公开预算
  └─ T1 单步重放一致 ──有限归纳──> 整条重放一致
       └─ 合法 mask→Y 反例（不依赖其他定理）

uniform risk/cost 误差 + 有限相同动作集合
  └─ T2 三次比较的 argmin 稳定性
       └─ 额外 Bellman Q* 假设 + 有限 T ──> T2-H

指定真实成本分解
  └─ T3-C/T3-R 相减恒等式 ──> T3-B 批量阈值

均匀独立 concept bits + noise 与 bits 独立
  └─ P(E=e,Z=z)=P(E=e)/4
       ├─ T4-D 一般误差耦合结果
       └─ 两噪声额外 iid ──> T4-V ──> T4-P 成本临界式

有界变量 mgf（二阶导 = tilted variance ≤1/4）
  └─ Hoeffding 单边界 + 跨病例独立
       └─ 有限 M union bound ──> T5 同时上界 ──> 可认证集合内选择

显式 Bernoulli 构造 ──> T6 选后失准反例
完整条件概率 + selection 可测 ──tower property──> T6 保持性质

固定可见状态 + 完整 STOP/28-singleton 菜单 + 两类隐藏病例
  └─ 逐样本 Boolean-error softmax 分母不同 ──> T8 期望排序反转
       └─ 交叉熵/KL 恒等式 ──> 完美模仿仍选期望效用较差动作

菜单 A(h) 由可见状态和冻结协议确定
  └─ 代入 f(h,a)=g(h,A(h),a) ──> 任意集合打分决策可由无限制逐候选打分表示
       └─ 外生菜单反例 + 有限模型容量 caveat
```

## 2. 假设总账

| ID | 假设 | 使用位置 | 实现/实验如何检查 | 不满足时的最小处理 |
|---|---|---|---|---|
| A1 | 控制器/任务头/候选生成器不读 raw x、未查询预测或标签 | T1 | 结构化只读接口、未查询字段投毒、固定 transcript replay | 移除读取；否则声明额外信息版本 |
| A2 | 输入长度、实际时延、数据缺失元数据不成为隐藏控制输入 | T1 | 测试同 H 改 x/latency 日志；预算采用冻结 κ(H,A) | 实际 wall-clock STOP 标为 timing-channel 分支 |
| A3 | 相同状态和相同外生随机数产生相同动作 | T1 | 固定 seed；控制器无隐式跨病例可变状态 | 显式扩展状态，固定服务版本 |
| A4 | 风险/成本误差对当前同一动作集同时有界 | T2 | 不把平均 ECE/Brier 当 uniform 界；toy 可精确枚举 | 只保留条件性解释，不声称已满足 |
| A5 | 多步估计逼近真实 Q*，而非一步收益；uniform 范围覆盖真实转移下任意合法动作序列/策略可达的历史，至少含学得策略的全部轨迹 | T2-H | 明确 Bellman target/终端条件；不能仅验证训练或 oracle 支持；强非贪心基线 | 删除多步最优或 regret 主张 |
| A6 | 有限时域 T，动作停止后吸收；期望成本有限 | T2-H | 最大轮数 K、预算、失败/重试上限 | 加入可验证上限再应用 |
| A7 | 固定并发/缓存/精度下成本可按所给模型分解 | T3 | pilot 测 setup、query、controller、head 与总 wall-clock residual | 总实测成本优先；若模型失配则不套等式 |
| A8 | 最终任务头 h 在基线和自适应中相同，其他头调用归 O | T3 | 单独计时，避免把额外 f 调用漏掉 | 重写成本分解 |
| A9 | C1,C2 iid Bern(1/2)，Y 为 parity | T4 | 合成生成器与穷举检查 | 只用于合成机制，不外推真实数据 |
| A10 | 噪声向量与真概念独立、查询一致、一次测量不重采样 | T4 | 明确 fixture 语义与缓存键 | 重新推导，不使用固定公式 |
| A11 | 两噪声 iid Bern(ρ)，ρ∈[0,1/2] | T4-V/P，仅此处 | 独立生成路径；相关版本改用 d | 采用 T4-D，不继续用 2ρ(1−ρ) |
| A12 | 分类头在 toy 达到 Bayes 最优 | T4 | 直接使用解析 Bayes decoder；learned head 另计误差 | 区分 Bayes reference 与学习曲线 |
| A13 | 完整候选系统族在认证前冻结，M 有限 | T5 | checkpoint/prompt/λ grid/split hash；禁止认证集再训练 | 重新独立认证或扩大预注册家族 |
| A14 | n 个校准单元 iid，与未来部署同分布 | T5 | split/group 审计；病例随机性独立；不能把编辑当独立样本 | 按独立家族取样，明示假设；shift 下不援引保证 |
| A15 | 终局损失属于[0,1]，每病例每策略仅贡献一次 | T5 | 日志 schema 与 numerator/denominator 单测 | 预固定 clipping/normalization；不误用原 CE |
| A16 | p 是真实 E[C|F]，selection 由 F 决定 | T6 保持性质 | 一般不可在有限数据完全验证 | 把它作为正向理论条件，不声称估计器完美 |
| A17 | 拒答不被伪记作正确；STOP ≠ abstention | T5 | 所有 STOP 后预测进 error 分母 | 若引入 abstention 另证 conditional answered risk |

| A20 | 完整候选菜单是可见历史及冻结公开协议的确定函数，逐候选表示保留足够的 `(h,a)` 信息 | Choice 集合交互范围说明 | 对照 `choice_features.py` 的状态、预算、动作和公开候选生成配置；随机 cap/外部 availability 须显式入状态 | 不能主张通用表示等价；仅保留有限架构消融 |

## 3. 符号表：类型、单位与作用域

| 符号 | 类型/范围 | 单位或意义 | 作用域 |
|---|---|---|---|
| K | 正整数 | 固定测量项/查询组数，g∈[K]；是获取与计费粒度 | 全文 |
| D | 正整数 | 原子属性数，j∈[D]；不默认与 K 相等 | 共同设定 |
| X,C,Y | 随机变量 | 原输入、公开真概念、任务标签 | 全文 |
| Z_g | 有限类型化变量或有限乘积空间 tuple/vector | 查询组的自动测量，非真概念；T4 的组恰为单 bit | 全文 |
| H_t, \bar H_t | 有序历史 / 规范化集合 | 仅已获取证据 | T1–T3 |
| A 或 a | 获取集合或 STOP | 非空查询或终止动作 | T1–T3 |
| r_a | [0,1] | 固定动作后立即分类的期望损失 | T2 |
| κ_a | 非负实数 | 同一动作的期望新增成本 | T2 |
| λ | 非负实数 | 每单位成本对应的损失权重 | T2/T4 |
| ε,η,ξ | 非负实数 | 风险误差、成本误差、优化误差 | T2 |
| d_t | 非负实数 | Bellman action-value uniform 误差 | T2-H |
| T | 正整数 | 最多决策步数，停止后吸收 | T2-H |
| s,d_K,h,O | 非负成本 | 共享编码、全量响应、最终头、额外开销 | T3 |
| τ,q | 非负整数 | 获取轮数、获取概念总数 | T3 |
| a,d,o | 非负成本 | 每轮 setup、每概念边际、每轮 controller | T3-B；不要与动作 a 混用同一公式 |
| p_0 | [0,1] | 空历史直接停止概率 | T3 |
| ρ | [0,1/2] | 每概念边际 flip probability | T4 |
| d | [0,1] | P(E1≠E2)，与 T3 的成本 d 不同 | T4-D |
| u | [0,ρ] | 同翻转概率 P(E1=E2=1) | T4-D，ρ≤1/2 |
| M,n | 正整数 | 冻结策略数、独立认证病例数 | T5 |
| δ | (0,1) | 同时认证失效概率上界 | T5 |
| α | [0,1] | 总体终局风险目标 | T5 |
| γ,U_m | 非负 / [0,1] | 认证余量、总体风险上界 | T5 |
| F | sigma-field | selection 时可用的全部信息 | T6 |
| θ,q_a,π_a | 正温度 / 单病例教师分布 / 模仿器分布 | 完整 Choice 候选集上的概率，不是各动作独立错误率 | T8 |
| p,r,c,D_I,D_II | `p=.52`、`r=e^{-1/θ}`、`c=e^{-λ/θ}`、正分母 | T8 两类型构造参数 | T8 |

单位检查：T2 中 `ε`、`λη` 和 `ξ` 都是损失单位；T4 中 `λκ` 与 Bayes error 同单位。T3 中所有项必须统一为同一种成本；不能把 tokens 和秒直接相加。

## 4. 量词、概率模式、极限顺序

| 结果 | 量词及概率模式 | 范围 | 渐近/换序 |
|---|---|---|---|
| T1 | 对所有合法 h、x、x′、相同 u 的逐点确定性结论 | 下一真实查询前；同 replay 则整个轨迹 | 无 |
| T2 | 对给定 h 上所有动作的 uniform 误差事件条件成立 | 同一个有限动作集的 oracle；不是全策略最优 | 无 |
| T2-H | 对真实转移机制中任意合法动作序列/策略可达的全部历史、每 t 的 uniform Q* 逼近，包含学得策略轨迹，不限训练/oracle 支持 | 同一合法动作类、有限 T 的真环境最优策略比较 | 有限和，无极限 |
| T3 | 路径成本等式及对随机策略取期望 | 指定成本模型、同后端/并发/缓存 | 只需期望有限，无近似极限 |
| T4 | 固定显式分布下的精确 Bayes risk | population toy，而非有限样本学习率 | 无 |
| T5 | 条件于训练数据，以至少 1−δ 的校准抽样概率，对全部 M 同时 | 同分布总体平均风险；非每条轨迹或子群保证 | n,M 固定有限；无渐近近似 |
| T6 | 显式反例 + 几乎处处条件期望恒等式 | F 可测 selection | 无 |
| T8 | 一个固定可见状态下的显式有限分布，精确总体期望与 soft CE population minimizer | 完整 29 候选、二类隐藏病例；不外推真实 CUB | 无 |
| Choice 集合交互范围 | 对所有确定性菜单和任意有限实数集合分数，逐点决策相同 | 不比较固定神经网络容量、学习效率、概率校准或计算成本 | 无 |

未隐藏任何“先 n→∞ 再 K→∞”顺序。没有证明参数学习的一致性、收敛速率、贝叶斯最优 responder 的可实现性或一般 regret 的统计速率。

## 5. 调用定理的旁条件

| 工具 | 旁条件如何满足 | 不接受的替换 |
|---|---|---|
| 有限归纳 | T1 固定最大轮数，无新增概念后的无限循环 | 不限制重试仍声称程序一定终止 |
| 期望线性性 | T3 非负且有限期望；硬件 timeout 明确 | 用 p50 相加近似 p50 总和 |
| Chernoff / Markov | 指数非负；损失有界保证 mgf 有限 | 未截断 CE 或无界 latency 直接套同一界 |
| Hoeffding | n 个跨病例独立、有界、同分布终局损失 | 把同病例 T 个步骤或 CEBaB 编辑当 nT 个 iid 点 |
| Union bound | 有限 M 个预冻结系统，各失效概率≤δ/M | 测试后按效果减少“报告的 M” |
| Tower property | sigma(p,J)⊆F，C 可积 | selection 读取 F 之外额外特征却仍援引保持性质 |
| Soft CE/KL 恒等式 | 全部 q_a>0、候选集固定且完整、π 在概率单纯形 | 把 E softmax 偷换成 softmax(E utility)，或把 q 当独立 Bernoulli 风险 |

## 6. 反例尝试与结果

| 挑战 | 结果 | 对最终陈述的修订 |
|---|---|---|
| mask-only 完美预测 y 能否推翻 T1？ | 不能；路径合法继承已观察信息 | 明确给出 C1=Y 的反例 |
| controller 用真实 latency 递减预算是否仍 concept-only？ | 一般不是；可以编码原输入信息 | strict 版本使用公开/历史可预测预算 |
| 平均 Brier 很好是否推出 T2 uniform bound？ | 不成立；罕见动作/历史可有大误差 | 仅作条件定理，不宣称学得误差有界 |
| one-step risk 是否给 T-step regret？ | 不成立；互补 XOR 就可失败 | 单独要求 Q*，不从 r 偷换为 Q* |
| q<K 是否足以加速？ | 不成立；重复 setup/controller 可超额 | T3-B 精确开销阈值 |
| noise ρ=.5 时独立双查询有益？ | 不成立；gain=0 | strict inequality 与并列边界分开 |
| 固定静态 pair 能否在 XOR 匹敌自适应？ | 能完全匹敌 | XOR 仅证明互补，不能证明 instance adaptivity |
| 误差相关越强是否总更坏？ | 不成立；parity 可抵消同向错误 | T4-D 给出 0、.375、.5 同边际风险 |
| 相关轨迹步骤会破坏 T5 吗？ | 不会，完整轨迹是一个样本 | 独立性施加在病例间 |
| 空认证集合可默认部署 all-concepts？ | 不可由 T5 证明它安全 | 必须输出 no certificate；fallback 另审 |
| 在认证后重训或增加未预注册 λ 是否合法？ | 一般不合法 | 冻结候选家族；新增方案需独立认证 |
| 完整条件概率被同信息 selection 必然破坏？ | 不成立，tower property 保持 | T6 同时写出正向保持性质 |
| 完美拟合逐样本 Choice softmax 是否最小化期望错误＋成本？ | 一般不成立；T8 给出与当前 29 候选、λ、温度一致的二类型反例 | 不写 Bayes 最优保证；与 proper 独立风险及 Bellman Q 目标分开 |
| set attention 是否具有无条件表达必要性？ | 若菜单由可见状态确定，则任意集合分数可代入定义为逐候选分数；若相同状态下菜单外生改变且共同候选相对排名反转，则逐候选分数不能表示 | 只把集合交互称为有限容量/归纳偏置假设，增加参数匹配对照；详见 `CHOICE_SET_INTERACTION_SCOPE_20260923.md` |
