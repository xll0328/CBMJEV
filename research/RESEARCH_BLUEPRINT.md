# 从想法到实验与论文：研究总纲 v3

日期：2026-09-21。资源假设已由用户确认：8×A100 或 8×RTX 4090；数据在服务器下载公开版本；新增专家概念标注与轨迹标注均为 0。A100 显存、可用时长、服务器路径尚未确定。

本文件统领此次扩展；旧版 proposal 保留为研究历史。这里的性能、机制普遍性与贡献均是**待检验假设**，不是实验结论。

## 1. 我建议真正立项的问题

> **When Is Adaptive Concept Acquisition Worth Its Cost?**
> 当概念由有误差的自动模型测量，且计算可以共享和批量化时，什么样的逐步概念获取策略值得使用，什么情况下应该直接一次问完？

中文工作标题：**有误差与共享计算下的自适应概念获取：适用边界、决策与审计**。

研究的对象不是“让 CBM 看起来像医生”，而是从静态概念向量走向**有成本的语义测量过程**。医生式逐步排查是直觉来源，不是临床能力或医生流程模仿的证据。没有新增专家轨迹仍可训练，因为训练集已有任务标签，可以评价额外测量对任务的实际作用。

推荐定位为**机制驱动的实证与方法研究**：明确一个容易被错误评估的问题，推导可检验的边界，建立严格测量环境，用简洁的策略和强近邻解释真实收益。是否最终升级为新算法论文，取决于相同噪声、动作空间与成本条件下，是否仍稳定优于强 AFA；不预先承诺。

## 2. 与上一版相比，真正改变了什么

1. **校准不再是核心创新候选。** BCEA 已讨论获取后重新校准；RouteCert 已讨论策略生成的终止模式、联合验证和小联盟获取。它们是必须引用的边界与对照，而不是等实验结束才补的 related work。[BCEA](https://arxiv.org/abs/2606.16667)、[RouteCert](https://arxiv.org/abs/2608.15520)
2. **有噪声获取不是新问题。** AFA、ECED、SEFA 等近邻决定了我们必须研究具体的语义回答误差与真实共享计算，而不能只把干净特征换成预测概念。[ECED](https://proceedings.mlr.press/v54/chen17b.html)
3. **理论负责解释机制，不用弱引理装饰贡献。** XOR、估计误差的决策界、Hoeffding 校准都明确标记为已知原理的实例化或解析扩展；没有查新支持就不写“新理论”。
4. **防旁路扩大到成本元数据。** 实际 token 长度、时延、样本 ID、缓存命中都可能携带输入信息。严格主版本策略只用语义历史与预冻结的声明成本；实际费用在策略之外记录。
5. **8 卡用于更干净的实验。** 优先投入独立响应种子、交叉拟合、强基线和实际部署测量，不先堆更大的控制器。

## 3. 两个主张，而不是十个贡献

### C1：测量过程决定适应性的收益区间

待证伪主张：在固定概念库、回答器和分类头下，**响应误差的任务相关结构**与**共享/批量计算成本**共同决定自适应获取相对静态批量的风险—成本前沿；仅凭概念平均准确率或查询数无法判断是否值得部署。

最低证据：解析反例 + 受控噪声机制实验 + 至少两类真实数据/回答器成本制度上的可复现边界。若现实中没有可观察的转折，只能报告 toy 解释，不能宣称普遍规律。

将C1拆成两个具体可失败的预言：P1，在匹配每概念边际质量后，改变错误耦合仍改变task–cost前沿，并可由训练统计预测方向；P2，同一批策略按query count排序与按live latency排序可能反转，训练/validation拟合的共享成本模型能在保留配置上预测反转。只有toy支持P1、或只有人为加延迟支持P2时，均不足以写真实系统主张。

### C2：对真实测量过程建模，是否产生可归因的决策收益

待证伪主张：使用实际自动回答训练、直接评价候选批量的终局风险、计入真实成本并满足语义信息边界，可以在某些非平凡预算区间改善决策；收益不应由理想真值回答、未计费计算或更强分类头解释。

最低证据：同 R、同 f、同数据划分、同动作集的强静态与强 AFA；noisy/ideal、single/batch、unit/actual 三项关键消融；真实 lazy inference 计时；全部信息路径回归测试。

若 C1 成立而 C2 不胜强 AFA，论文改为测量与边界分析，方法只作可复现实例。若两者都弱，停止新算法包装，不靠更大 backbone 救叙事。

## 4. 三层研究范围

| 层次 | 内容 | 为什么值得做 | 进入条件 |
|---|---|---|---|
| 必做主线 | 固定概念库，实例自适应 subset/order/batch/STOP，hard typed response | 可用公开概念标签严谨检验 | 直接开始 |
| 有针对性的深化 | 错误耦合、有限深度前瞻、选后风险、同概念不同测量模式 | 解释主线失效/成功 | 对应主实验出现清楚现象 |
| 后续独立方向 | 开放概念生成、迁移新概念、持续学习、真实医生协作 | 有潜力但验证负担不同 | 本论文不依赖；无专家标注时不承诺临床语义质评 |

不把所有分支做成主实验笛卡尔积。主文最多五块实验、三个基线族、三个独立训练种子。

## 5. 为什么这次不是简单的 AFA 换数据

必须实测的四个结构差异：

**观察不是揭示真值。** 取得的 z 是 R 对 c 的估计。两个同样 85% 准确的回答器可以在下游互补任务上表现完全不同；而且错误相关并不总是坏事，例如 XOR 中共同翻转会相互抵消。因此报告“相关越高越差”也不成立。

**费用不是概念个数的线性函数。** 同一图像编码、同一文本前缀、批量候选评分可能共享成本。一次获取 20 项可以比 5 次单项调用便宜。最优动作应包括 batch 与 all-remaining，而不是只比较查询顺序。

**选择本身也是信息路径。** 策略若先看图再选概念，即使分类头只看概念身份，也可能间接利用图像信息。另一方面，合法历史生成的 mask 可以携带已有概念信息，并不自动构成泄漏。

**训练目标不能假设额外测量总有益。** 对冻结的有限容量分类头，获取有误概念可能使个别样本变差；不能把负 loss-drop 截成零，也不能把置信度最高当价值最大。理想 Bayes 头可忽略新信息的性质，不等于实际拟合头单调改善。

以上不是各自的首创主张。贡献成立需要它们共同解释真实对照中的具体差异，而不是只写在 motivation。

## 6. 主方法的最小配置

使用公开训练数据 D={(x,c,y)}。三个模块独立：

- R(x,q)：仅此模块可看原输入。训练 c 的语义监督后冻结；主版回答不读之前的诊断/概念历史。
- f(H)：mask-aware MLP 或 DeepSets，只读已获得的离散概念 ID、值与合法状态。
- r(H,A)：预测“执行 A 后立即用 f 判断会错的概率”；STOP 的标签由当前 f 的错误事件生成。它不是候选动作 softmax。

选择 `argmin_A [r(H,A)+λ κ_declared(H,A)]`，动作含 STOP、single、少量 pair/batch 和 all-remaining。所有候选生成只依赖 H 与训练冻结的统计。

这是一个透明的起点，不宣称算法新颖。两条升级路线只选有证据的一条：

1. **互补性明显**：用有限深度 Bellman risk-to-go 替换 one-step 风险，与同样深度/动作预算的 ACO、BRiG 比较。
2. **单步风险足够但误差结构关键**：保留小模型，研究自动响应与理想真值训练的策略迁移损失、不同错误耦合下的失效边界。

禁止默默把“大模型策略”作为贡献。NanoJev 的角色是开放 typed responder 与可比较的候选打分实现；普通概念分类器必须同场。

## 7. 公开数据各自承担什么证据

| 数据 | 主用途 | 不能承担的结论 |
|---|---|---|
| CUB | 较大概念池、实例异质性、视觉回答与真实批量成本 | 不能用 class-majority 概念冒充逐图真值；鸟类结果不是医疗证据 |
| CEBaB | Jev/NanoJev 原生文本接口；四方面可枚举决策；已有文本 edits | 不能证明大概念池 scalability；不是临床因果干预 |
| Derm7pt | 七项分类概念、已有双图像、诊断目标、小池精确搜索 | 没有真实问诊轨迹；回顾性病例结果不等于临床安全 |
| SkinCon/DDI | 条件性语义/域偏移验证 | 访问、去重、疾病映射未完成前不能承诺作为必做主结果 |

默认 CUB + CEBaB 提供核心证据，Derm7pt 下载与语义质量通过后纳入医学验证。不能因为 Derm7pt 小就用更多轨迹把有效样本量放大。细节见 [数据协议](../execution/data/DATA_PROTOCOL.md)。

## 8. 关键机制实验：如何做才不是堆 ablation

### M1. 区分测量噪声与概念不充分

同 split 比较 raw x→y、全量真实 c→y、全量自动 z→y。它们分别回答表征能力、概念库充分性、回答器质量；不是公平预算策略排名。若真实 c 本来不够，应报告瓶颈上限，不能全怪策略。

### M2. 在平均错误率相同下改变错误依赖

第一层用解析二概念环境：独立翻转、共同翻转、互斥翻转，保持边际错误率一致，直接计算任务风险。第二层在真实样本训练分布上拟合合法混淆模型并生成受控扰动；固定每概念边际，改变耦合。第三层测真实 R 的错误共现/条件共现，检验解析现象是否有现实对应。

不将一次随机打乱误差当成“控制了一切”：跨样本打乱还会破坏难度、类别和可见性条件。应比较类/可见性分层的耦合控制，报告剩余差异；真分布因果结论保持克制。所有噪声模型在训练/验证拟合，不用 test 决定扰动设计。

### M3. 单项价值与集合价值

比较 myopic-single、myopic-batch、lookahead-single、lookahead-batch，使用相同候选覆盖和总搜索预算。这样才能区分“看得远”和“真正批处理省成本”。对 CEBaB/Derm7pt 可以枚举**子集**，但完整状态还含各值；128 个子集不等于仅 128 个 MDP 状态。

### M4. 将 cost model 作为可控轴

受控轴包括共享预处理占比、每次请求固定开销、边际候选成本、batch scaling。模拟只用于机制；服务器实际分别测 cheap shared-head、独立 typed query、batch typed query，主图同时显示 query count 和端到端 latency。若只省 query，就只报告 query。

### M5. 校准与停止：护栏而非发明

冻结有限完整策略后，在独立 calibration groups 上估计 terminal risk；有证书的候选可能为空，这是诚实结果，不通过降低标准硬选一个。总体风险保证不是每个路径/病种保证；小数据下证书可能无信息。需要路径保证时采用并比较 RouteCert 对应设计，不把本项目简单 Hoeffding 界改名。

## 9. 值得保留的六条后续方向

| 方向 | 可执行设计 | 新增标注 | 触发条件 / 删去条件 |
|---|---|---|---|
| verify 而不是只问新概念 | 同概念另一个模型/分辨率/临床-皮肤镜模式作为付费动作 | 无，现有 c 评估 | 单源错答造成早停才做；两次同 deterministic 调用不算新证据 |
| concept-label-free | R 冻结，仅 y 训练 f/策略；c 只最终审计 | 无 | 主监督路线成立后做；不能称 zero-shot |
| 跨概念/任务策略迁移 | 固定语义定义与schema，held-out concept family 或 dataset | 无 | ID lookup 无法迁移时才值得语义controller；先排除ontology不一致 |
| instance-adaptive concept granularity | 大组→具体属性，显式嵌套动作与费用 | 无 | CUB grouping由定义预固定；不要拆出无真值概念 |
| intervention-aware replanning | 公共真值纠错后，固定后续路径 vs 重新规划 | 无 | 作为诊断工具，不假定部署中总有人类纠错 |
| robustness / domain shift | 受控图像质量变化或许可允许的外部集 | 无 | 防止改变真实概念含义；不从外部test调阈值 |

优先级：主线完成后，最多选择一项作为强化结果，其他留未来工作。

## 10. “边实验边写”到底可以预写多少

现在可写：问题定义、概念状态语义、信息边界、理论假设和证明、训练目标、数据处理、对照公平性、统计计划、局限；Figure 1 架构和解析 toy 图可先完成。

必须等结果：性能摘要、哪些数据有收益、贡献中的比较动词、最强基线排名、真实效率数字、校准改善、失败频率与最终结论。Results 先留字段而不是编句子。

论文贡献措辞采用两阶段：当前“we investigate / we provide a protocol / we derive under stated assumptions”；得到证据后才将满足条件的一项改为“we demonstrate”。具体英文草稿见 [预写稿](../paper/STORY_AND_DRAFT.md)。

## 11. Go / No-go 决策树

1. 数据与回答器：实例语义标签可用吗？全量自动概念有任务信号吗？否则先修数据/回答器，别训复杂策略。
2. 静态成本：all-at-once 是否已接近单次获取成本？若是，此后端通常没有速度空间；保留为必要负对照，换真实按需后端不是人为拆慢。
3. 基础异质性：小树/强静态顺序是否已接近枚举上限？若是，不能靠复杂policy制造贡献。
4. 强 AFA：在 matched noisy response、同 batch/STOP 后，改善是否仍在？若否，方法降级为基线，主攻科学边界。
5. 跨数据与真实成本：至少两类证据一致吗？若仅一个小集显著，缩小claim，必要时停止大投入。

工程立项门槛建议：预设精度容忍 1pp、相对全量成本节约 25% 作为资源筛选目标；不是论文成功定义。相对最强静态/AFA 的差异与置信区间仍必须单列。阈值在 validation 选定，禁止 test 后移动。

## 12. 实施顺序与最终交付边界

第一批不是8卡同时跑全部组合，而是：下载验收→100样本成本profile→全量c/z上限→同f静态/贪心/强AFA→live lazy确认→三seed与第二数据→机制和可靠性→按证据收敛论文。

本研究包提供设计、理论、schema、协议测试、图稿和论文预写材料；真实数据集尚未下载，模型权重尚未锁定，完整视觉/NanoJev训练与强基线适配必须在服务器实施并测试。绝不把文档完备或toy程序通过称作真实实验完成。执行任务与验收见 [实施规格](../execution/IMPLEMENTATION_SPEC.md)。
