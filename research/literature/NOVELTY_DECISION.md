# 新颖性决策：以可证伪的科学结论替代 API 拼装

日期：2026-09-21。状态：**建议继续，但否决“序贯 CBM + Jev + 校准”作为独立创新叙事。** 本文是查新后的实验决策，不是结果报告；尚无实验支持下述候选主张。

## 已被覆盖的内容

- 根据已观测值选下一特征并停止：经典 AFA；监督非贪心风险头也已有 [ACO](https://proceedings.mlr.press/v235/valancius24a.html) 与 [BRiG-AFA](https://arxiv.org/abs/2608.02305)。
- 相关噪声影响测试价值：[ECED](https://proceedings.mlr.press/v54/chen17b.html) 已专门研究；XOR、互补性与非贪心优势只能作诊断，不是新的科学结论。
- 自动向视觉模型追问并验证证据：[ReCoVERR](https://arxiv.org/abs/2402.15610) 已有。
- 新证据后重新认证、策略产生分组后的有效性：[BCEA](https://arxiv.org/abs/2606.16667)、[RouteCert](https://arxiv.org/abs/2608.15520) 已直接覆盖关键思路。
- 不需要专家查询轨迹：可以利用既有标签、离线完整特征/概念数据学习，AFA 与模拟干预文献早已可行。“不新增标注”是现实约束，不是新算法。
- Jev/NanoJev 的决策头、CE/Brier、有限策略族风险上界、批量动作、硬概念本身，都不能组成单独创新清单。NanoJev 是实现选项；若小 MLP 同样好，不应保留更大模型来制造方法复杂度。

剩余空间必须由“前人任务中未量化的现实机制”及有反证力的实验证据支持，不能靠给变量换名。

## 候选 A：边际语义质量不能预测自适应系统的可靠性

### 可检验增量

目标不是再次证明噪声相关性存在，而是检验：**在公开 CBM 数据与实际自动响应器中，单概念准确率/校准相近的测量器，是否因为错误的联合结构而产生稳定、可解释的策略排名反转；这种反转能否用训练数据可估计的统计量预测？**

令公开标注为 c，自动回答为 ĉ，错误指示 e_j=1[ĉ_j≠c_j]。单概念质量只测 P(e_j=1)；真正相关的量还包括给定任务、可见性、已知语义状态后，多个错误是否共同发生，以及这种共同错误是否沿策略路径被放大。估计联合结构时可使用训练/验证的 c,y；部署控制器不得获得未知 c、y。

与现有工作的差异定位：对真实“机器测量语义”做受控响应通道比较，区分“概念间本来相关”与“测量错误额外相关”。只有实际数据的效应、可预测性和干预结果才可能构成增量；不能称为新的有噪测试理论。

### 最小反证实验 A0

1. 先在 CEBaB 四个概念组开展；锁定按原始评论/编辑家族分组的数据划分。既有概念标签仅用于训练、误差诊断及合成通道；无新增人工标签。
2. 固定真实 (c,y) 与任务头，构造两个显式生成的合成回答通道：每概念混淆矩阵匹配，错误联结结构不同。二元概念可用共享潜变量耦合 Bernoulli 错误；多类概念固定混淆矩阵、改变错误随机数的依赖。不能把随意打乱 ĉ 当作纯误差相关性干预，因为那会同时改变概念语义和标签关联。
3. 概念真值与回答可取值组成观测状态，穷举小概念空间的策略/动态规划参照；比较贪心、树、ACO/BRiG 类同信息方法与全批量。
4. 在独立真实响应缓存上验证方向，并给出控制后残余混杂；仅靠真实输出的条件重排不能声称完全因果识别。CUB 的可见性、Derm7pt 的缺失状态必须分层处理。
5. 报告配对风险—成本曲线、错误聚集、STOP 子群风险，以及单变量质量统计对策略收益的预测能力。用训练分布拟合诊断量，在另一响应器/数据划分上预测，避免对同一结果事后解释。

**最小否决条件：** 控制边际质量后效应接近零；只在精心构造 XOR 中成立；真实通道效应完全由难度/可见性混杂解释；或者普通 AFA 学到联合结构后已消除所有预期问题。最后一种情况不否定科学诊断，但否定“必须使用我们新控制器”的方法主张。

**继续条件：** 至少一个真实响应器比较或预注册通道干预重复出现有实质量级的效应，且可由训练统计预测而非仅事后归因。量级阈值应在先导实验后、最终测试前冻结，不建议无依据预设一个通用百分点。

## 候选 B：共享计算成本决定应该“一问一答”还是批量

### 可检验增量

目标不是说批量便宜，而是建立并验证：**语义测量的依赖收益与共享计算成本共同决定最优查询粒度；只用概念数评估会系统性地错排方法，成本感知动作选择何时能挽回真实收益？**

对动作 A 使用 κ(A|H) 而非 Σκ(j)。κ 包含视觉编码、前缀、解码、控制器、调度等实际增量成本。查询次数、GPU 时间、端到端延迟不是同一指标，吞吐与单样本延迟也须分开。批量可能改变回答内容，因此先检验回答的批量不变性：若不成立，应缓存/建模 R(x,A)，不能将独立 R(x,j) 拼接成假批量实验。

简化串行模型可作为 sanity check：一轮固定开销 C₀、每概念增量 Cq，全部 K 个概念一次批量成本约 C₀+KCq；自适应 L 轮、Q 个概念成本约 LC₀+QCq+Cpolicy。只有 (K−E[Q])Cq 大于 (E[L]−1)C₀+E[Cpolicy]，才可能仅凭少问概念省时。它是成本记账关系，不是可发表的新定理；真实后端应用 κ 实测代替线性近似。

### 最小反证实验 B0

1. 采用同一冻结回答器与同一任务头，比较全部一次批量、静态小批、单问自适应、可选批大小的自适应。选择器使用同等观测与候选集合。
2. 在同一 GPU/精度/图像尺寸下记录 warm 与 cold、单病例与多病例吞吐；GPU 计时同步，报告重复测量分布。先真实测量 κ，再用离线轨迹做大规模策略搜索；最终获胜点必须端到端实测复核。
3. 共享编码器多头为负控制；昂贵独立视觉测量/不同分辨率为另一真实端点。人为调整固定开销只能用于机制相图，不得当成真实加速证据。
4. 以两轴相图展示固定开销比例与语义互补/错误结构下，哪种查询粒度在匹配风险时更优；对 ACO/SEFA/BRiG 基线开放相同批动作和成本信息，区分“新动作空间的增益”和“新学习算法的增益”。
5. 先在 CEBaB/Derm7pt 小概念空间检验，再在 CUB 验证不是仅靠小维度穷举；8×A100 足够并行缓存/训练，4090 版本缩小模型和候选动作即可，核心机制不应依赖巨大训练预算。

**最小否决条件：** 所有真实后端中全批量均占优，或同信息、同动作、同成本的 AFA 基线得到同等前沿而我们的额外模块无增益。前者仍可支持“何时不应自适应”的负结论，后者要求删除新方法优势，只保留有充分广度的机制/评估论文。

**继续条件：** 出现可复现的真实成本边界或排名反转，且预先估计的成本模型在未用于拟合的后端配置上预测方向。只有实际支持时，才附加“成本感知控制器改善前沿”的方法子主张。

## 候选 C：策略选择后可靠停止

### 候选形式及决定

可检验问题是有限认证样本下，复杂查询策略能否获得足够覆盖且保持真实标签风险目标。但 [RouteCert](https://arxiv.org/abs/2608.15520) 已研究策略产生的模式与认证碎片化；[BCEA v4](https://arxiv.org/html/2606.16667v4) 已比较 acquisition 后精确与实用校准。**不建议将其作为独立主创新；保留为 A/B 的必要评估层。**

### 最小反证实验 C0

固定完整策略，包括任何 STOP 阈值，分开训练、开发、认证、测试。比较原静态阈值直接迁移、完整流程终局认证、若资源允许再做终止模式条件认证。使用有限预注册策略/阈值网格时校正选择；不能在同一认证集反复改策略再按单次认证报告保证。区分：全体终局错误率、回答子集错误率、预测集 coverage、对全模型一致性，四者不可互换。

反证新方法必要性的最小结果是：简单现成的完整策略认证已足够，额外“policy-conditioned calibrator”没有稳定收益。若只有极少模式有足够认证样本，应如实报告覆盖损失，不把不回答的病例悄悄从成本分母排除。认证失败概率 δ 是对认证样本随机性的陈述；一次有限测试集经验错误率超过 α 并不自动推翻定理。

## 最终推荐：最多两个主张

建议题目方向：**When Is Adaptive Concept Measurement Worth It? Semantic Error Dependence and Shared-Compute Costs**。这是暂定研究问题，不是已经证明的结论。

1. **主张一（有条件保留 A）：** 在指定公开数据和自动语义响应器上，边际概念质量不足以预测自适应风险—成本表现；分离概念依赖与测量错误依赖后，可识别并预测其失败/获益区域。
2. **主张二（优先 B）：** 显式测量共享计算的非加性成本后，最优获取粒度与方法排名发生可解释变化；报告真实适用边界，只有实测支持时才宣称控制器加速。

可靠停止、严格语义瓶颈、无专家轨迹、公开标注使用、NanoJev 与 MLP 对照构成方法和验证基础，不再单列为创新。

## 立项门槛与停止扩张条件

| 阶段 | 最小产物 | 不通过时的决策 |
|---|---|---|
| G0 语义合法性 | 回答器在公开 c 上显著优于无信息参照，缺失/不适用状态清晰，控制器无 x/latent 旁路 | 先修响应器与数据定义，不启动昂贵策略训练 |
| G1 机制可辨识 | A0 受控通道保持指定边际，B0 成本计时可重复，至少小空间参照正确 | 删除含混“噪声鲁棒/高效”主张，修协议 |
| G2 强基线 | ACO 与至少一项 SEFA/BRiG 同信息公平运行；全批量与静态树纳入 | 不进入论文主实验；不得只和随机比较 |
| G3 主张证据 | 至少一个候选在真实响应器上成立，第二数据集/后端能检验其边界 | 转为窄机制论文/协议报告，或明确 no-go，不用新模块掩盖负结果 |
| G4 可靠性 | 独立认证与冻结测试、真实标签风险、成本分母完整 | 将保证降为经验结果；不写医疗部署安全 |

这条路线无需新专家标注，但并不等于零标签或零监督。公开 c 用于语义学习/校准/诊断，公开 y 用于风险与策略学习；所有使用范围应写进 split manifest。已有公开数据的泛化限制不能靠“像医生看病”的叙述消除。
